# Прогноз спроса для небольшого магазина

Рабочий прототип веб-приложения: импорт продаж и остатков из CSV, прогноз по среднему дневному спросу, расчёт количества к заказу, поиск, сортировка и выгрузка результата. Данные обрабатываются в браузере и никуда не отправляются.

## Запуск

Откройте [демо](https://pepelaz1.github.io/demand-forecast-web/) или запустите статический сервер в корне проекта (например, `python -m http.server 4186`). Node.js для использования приложения не нужен. Кнопка **«Загрузить пример»** показывает готовый расчёт.

## Форматы файлов

Продажи (`UTF-8`, запятая или точка с запятой):

```csv
date,sku,quantity
2026-11-03,Кофе зерновой 1 кг,7
```

Остатки (`UTF-8`, необязательный файл; значения также можно заполнить прямо в таблице):

```csv
sku,stock,lead_days
Кофе зерновой 1 кг,3,7
```

Русские названия столбцов `дата,товар,количество` и `товар,остаток,срок_поставки` тоже поддерживаются. SKU в двух файлах должны совпадать. Продажи суммируются за заданное окно, заканчивающееся последней датой в файле. Если история короче окна или остаток отсутствует, прогноз показывается с предупреждением, но рекомендация к заказу не выдаётся как достоверная.

Формулы: `спрос в день = продано / дни истории`; `прогноз = спрос в день × горизонт`; `к заказу = max(0, ceil(спрос в день × срок поставки − остаток))`. Прогноз показан до 0,1 единицы. Сезонность, акции и автоматическое обучение не учитываются.

## Разработка

Сборка не требуется. Проверка расчёта: `npm test` или `node forecast.test.mjs`. Для публикации включите GitHub Pages из ветки `main`, папка `/ (root)`.

Это демонстрационный пример. Коммерческое внедрение, дополнительные источники данных и поддержка согласуются отдельно.
